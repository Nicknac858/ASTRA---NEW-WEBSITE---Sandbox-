# Afterimage CP07 — archived concept

**NOT APPROVED FOR HIGHER RANK.** Archived at Nick’s request on November 21, 2026. Retained for possible adaptation for another client; no client reuse has been authorized or performed yet.

This preserves the final Afterimage design: photographic projection scrims, continuous scroll, Hanken Grotesk + Bodoni Moda, dynamic geometry, and elegant hover/disclosure motion.

## Run the archive

From this directory, run `npm ci` and `npm run build`. Serve `dist/` with a static HTTP server. Do not open the HTML directly with file://. The build copies licensed fonts from locked npm dependencies into the output.
